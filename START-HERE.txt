LUXWARE WINDOWS 1.4.1 — ONE FIXED PRESET

Extract the ENTIRE ZIP. Open Luxware.exe on Windows. Keep the model and DLLs together.

1. Choose the Roblox window.
2. First Person = camera input. Third Person = free cursor. Both share ONE preset.
3. Start scan, then return to Roblox.
4. F6 toggles aim + clicking. F6 again stops input.
5. Ctrl+Alt+Esc / STOP ALL stops everything.
6. Ctrl+Shift+R / Reset target clears the lock and stops input. F6 acquires again.

Aim stays fixed. Clicker CPS and crossbow pulse CPS are independently editable and saved.
Toggle records a keyboard key/chord or mouse button. Default F6; press once on, again off.
Snap/no smoothing, one entity, left click and 40% duty remain fixed. Old tuning settings cannot override this profile.
1000 Hz is an input-check target, NOT 1 ms capture/detection.

Saved avatar views remain local. On a fresh PC, scan your visible body in third person,
return here, click Mark myself and draw tightly around YOUR body in the frozen preview.
This is done once per outfit/reference update; you do not repeatedly select an opponent.
Without your saved reference, clicking works but aiming waits for that setup.

No detected player = free mouse; activated normal clicking continues.
Behind-camera players cannot be detected. Bring them back into view to reacquire.

Updates checks/downloads happen on launch. Use Updates -> Install update when ready.
The Updates page contains no tuning controls. If the detector reports missing runtime
files, keep the complete ZIP contents together and use the included official Microsoft
Prerequisites\VC_redist.x64.exe when its runtime is missing.

Tested fixed baseline. Exact PvP accuracy, game input acceptance and performance vary
by hardware/game settings. See README.md, VALIDATION.md and the included reports.

OPTIONAL AUTO CROSSBOW
Open Auto crossbow... Record your crossbow slot key and normal-weapon return key.
Slots use one letter/number each. Choose Recorded toggle key (default F7, also
supports Mouse 3/4/5) or Automatic (active F6 input + fresh detected player).
Close setup, focus the game and activate F6 again. In toggle mode press your
recorded trigger too. Initial/repeat wait is fixed at 1.10 seconds. Regular
clicking pauses briefly for equip -> one shot -> return, then resumes.
This does NOT read cooldowns or verify that the game accepted a shot/slot key.
No eligible player stops auto-mode cycling; ordinary activated clicking continues.
F6 off or Ctrl+Alt+Esc stops cycling. Focus loss never types into another app.

Crossbow pulse CPS sets one click pair's press/release timing, not shots/sec.
The 1.10-second wait remains. Different CPS does not bypass the game cooldown.
